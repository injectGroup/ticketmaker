# Support

This document explains how to get help with **Quick Ticket Maker**.

---

## Before you ask

1. Check the [README](README.md) and [docs/README.md](docs/README.md).
2. Search existing [Issues](https://github.com/injectGroup/ticketmaker/issues).
3. Confirm you are on the latest `main` commit and that `flutter pub get`, `flutter analyze`, and `flutter test` succeed locally.

---

## Channels

| Need | Channel |
| --- | --- |
| Bug in the app | GitHub Issue using the Bug Report template |
| Feature idea | GitHub Issue using the Feature Request template |
| Contribution / process question | GitHub Issue or maintainer direct message |
| Security vulnerability | [SECURITY.md](SECURITY.md) — **private only** |
| Code of Conduct concern | `conduct@inject.group` |
| Access / repository permissions | Inject maintainer |

---

## What to include

- Flutter / Dart version (`flutter --version`)
- Target platform and OS
- Commit SHA or app version
- Clear reproduction steps
- Logs or screenshots with **secrets redacted**

---

## Response expectations

Inject maintainers triage Issues as capacity allows. Security reports follow the SLA in [SECURITY.md](SECURITY.md). There is no guaranteed public SLA for feature requests.

---

## Out of scope for support

- General Flutter tutorials unrelated to this repository
- Support for unofficial forks
- Production ticketing / payment systems not present in this codebase
